## 1. 中心的な問い

ロボティクスの教科書を開くと、運動方程式は必ずラグランジュ法で導かれます。

$$\frac{d}{dt}\left(\frac{\partial L}{\partial \dot{q}_i}\right) - \frac{\partial L}{\partial q_i} = \tau_i \quad \text{(ラグランジュ方程式)}$$

ところが自動車・航空機・船舶の教科書を開くと、ほぼ例外なく
Newton-Euler 形式が使われています。

$$m\mathbf{a} = \mathbf{F} \quad \text{(Newton の第2法則)}$$

$$I\boldsymbol{\alpha} = \mathbf{M} \quad \text{(Euler の回転方程式)}$$

**なぜ同じ「剛体の運動」を扱いながら、使う方程式が違うのか？**

答えは「どちらかが正しい」のではなく、**問題の構造**——拘束の種類、
支配する力の性質、最終的な用途——によって、どちらが素直かが変わるからです。

この文書は、その違いを実際に動くシミュレーションコードで示します。

## 2. 3つの力学定式化の全体像

### 定式化の比較

| 定式化 | 基礎となる量 | 最も得意な対象 | 苦手な場面 |
|---|---|---|---|
| **Newton-Euler** | 力・モーメント(ベクトル量) | 非ホロノミック拘束・非保存力・制御指向設計 | 多体系で式が煩雑になりやすい |
| **ラグランジュ** | エネルギー(スカラ量) $L = T - V$ | ホロノミック拘束・保存系・ロボットアーム | 非ホロノミック拘束で未定乗数が必要 |
| **Kane の方法** | 部分速度に基づく d'Alembert 原理 | 14自由度フルビークルなど大規模多体系 | 手計算では直感が掴みにくい |

### どちらが「正しい」か

どちらも**同じ物理現象を記述する正しい方程式**です。
ラグランジュ法を使って自動車の運動方程式を立てることも、理論上は可能です。
しかし、次の節で示すように、問題の構造によって「素直さ」が大きく異なります。

## 3. ラグランジュ法が輝く場面 — ロボットアーム

### なぜロボットアームにラグランジュ法が合うのか

2リンクロボットアームの一般化座標を $q = (\theta_1, \theta_2)$ とします。

```
       θ₁
  O ---+--- link1 ---+--- link2
       ↑              θ₂
    joint1          joint2
```

この系でラグランジュ法が自然に機能する理由は3つあります。

**理由 1: ホロノミック拘束**

関節の拘束は「座標どうしの関係」です。一般化座標 $(\theta_1, \theta_2)$ を選ぶと
拘束が自動的に消えます。Lagrange 乗数（未定乗数）は不要です。

拘束が消えた後の自由度: ちょうど2 $(\theta_1, \theta_2)$。
ラグランジアンは単純なスカラ関数になります:

$$L(q, \dot{q}) = T(q, \dot{q}) - V(q)$$

**理由 2: 保存力が主役**

重力はポテンシャル $V(q)$ を持つ保存力です。ラグランジアン $L = T - V$ の
枠組みにそのまま乗ります。運動エネルギーと位置エネルギーの交換が自然に
表現されます。

**理由 3: スカラ関数から方程式が出る**

スカラ関数 $L$ をそれぞれの一般化座標で偏微分するだけで、
機械的に運動方程式が出てきます。ベクトルの向きや符号を気にする必要がありません。

```python
# python/lagrangian_arm.py より抜粋
def manipulator_matrices(q):
    """
    L = T - V から d/dt(∂L/∂q̇) - ∂L/∂q = τ を計算すると
    平面2リンクアームの質量行列 M(q) が閉じた式で出る
    """
    q1, q2 = q
    c2 = np.cos(q2)
    m11 = I1 + I2 + M1*LC1**2 + M2*(L1**2 + LC2**2 + 2*L1*LC2*c2)
    m12 = I2 + M2*(LC2**2 + L1*LC2*c2)
    m22 = I2 + M2*LC2**2
    return np.array([[m11, m12], [m12, m22]])
```

### 運動方程式の標準形

ラグランジュ法を適用すると、ロボットアームの運動方程式は必ずこの形になります:

$$M(q)\ddot{q} + C(q, \dot{q})\dot{q} + g(q) = \tau$$

- $M(q)$ : 質量(慣性)行列 — 構成が体系的で美しい
- $C(q, \dot{q})\dot{q}$ : コリオリ・遠心項
- $g(q)$ : 重力項
- $\tau$ : 駆動トルク

この形式は **ロボティクスの世界標準**であり、
教科書・論文・ソフトウェア（ROS の urdf など）すべてがこの形を前提にしています。

### シミュレーション実証：エネルギー保存

デモ `python/lagrangian_arm.py` を実行すると、駆動トルク $\tau = 0$ のとき
全エネルギー $T + V$ が理論通り保存されることが確認できます:

```
シミュレーション時間 : 10.0 s (5000 ステップ)
全エネルギー(平均)  : 24.5250 J
エネルギー変動幅     : 6.453e-06 J (平均値の 0.00003%)
```

変動幅が平均値の **0.00003%** というのは、RK4 の数値誤差の範囲内です。
ラグランジュ形式が保存系を素直に扱えることの数値的証拠です。

## 4. Newton-Euler 法が素直な場面 — 輸送機関

輸送機関（自動車・航空機・船舶）では、次の4つの理由から
Newton-Euler 形式が標準になっています。

### 理由 1: 非ホロノミック拘束

自動車のタイヤには「横滑りしない」という拘束があります。
これは **速度の拘束** であり、座標の関係式に積分できません。

タイヤの非ホロノミック拘束は $v_{y,\text{wheel}} = 0$（タイヤ横方向の速度がゼロ）であり、
これは $f(q) = 0$ の形ではなく $A(q)\dot{q} = 0$ の形を取ります。座標変換だけでは消せません。

ラグランジュ形式でこれを扱うには Lagrange-d'Alembert 方程式が必要です:

$$\frac{d}{dt}\left(\frac{\partial L}{\partial \dot{q}}\right) - \frac{\partial L}{\partial q} = \tau + A^T(q)\lambda \quad (\lambda: \text{未定乗数})$$

未定乗数 $\lambda$ が増え、方程式系が大きくなります。

**Newton-Euler ではこの拘束を「タイヤが発生する力」として外力に書き下すだけです**:

```cpp
// src/car_dynamic.cpp より抜粋
// タイヤ横力を外力として直接扱う
double a11 = -(Cf + Cr) / (m * vx);   // 横力を横加速度に換算
double a21 = -(lf*Cf - lr*Cr) / (Iz * vx);  // 横力によるヨーモーメント
```

### 理由 2: 非保存力が運動を支配する

| 力の種類 | 輸送機関での例 | ラグランジアンへの組み込み |
|---|---|---|
| タイヤ摩擦 | コーナリングフォース | 不可（非保存力） |
| 空気抵抗 | 抗力 $D = \frac{1}{2}\rho V^2 C_D S$ | 不可（非保存力） |
| 流体抗力 | 船の粘性抵抗 | 不可（非保存力） |
| 推力 | エンジン・スラスタ | 不可（非保存力） |
| 重力 | 航空機・船舶の復原力 | 可能（保存力） |

ラグランジアン $L = T - V$ は保存力しか直接扱えません。
非保存力は「一般化力」として右辺に追加するしかなく、
ラグランジュ形式固有の利点（スカラ関数から方程式が出る美しさ）が
活きなくなります。

### 理由 3: 制御設計との直結性

現代制御理論は **状態方程式** を要求します:

$$\dot{x} = f(x, u) \quad \text{または} \quad \dot{x} = Ax + Bu \quad \text{(線形の場合)}$$

**Newton-Euler → 状態方程式: 素直**

```cpp
// src/car_dynamic.cpp — 線形状態方程式を直接構築
Eigen::Matrix2d A;
A << a11, a12,
     a21, a22;
Eigen::Vector2d B(Cf/m, lf*Cf/Iz);
// ẋ = Ax + B·δ として直接 RK4 で積分できる
```

**ラグランジュ → 状態方程式: M の逆行列が必要**

```python
# python/lagrangian_arm.py
def dynamics(state, tau):
    q, dq = state[:2], state[2:]
    M = manipulator_matrices(q)
    coriolis, gravity = manipulator_rhs(q, dq)
    # ここで M の逆行列を取る一手間が必ず入る
    ddq = np.linalg.solve(M, tau - coriolis - gravity)
    return np.concatenate([dq, ddq])
```

輸送機関では最初から状態方程式の形を目指すので、
Newton-Euler の方が設計の流れが自然です。

### 理由 4: 多体系では Kane の方法が優位

サスペンション・ステアリングリンケージまで含む
フルビークルモデル（典型的に14自由度）になると、
エネルギーの偏微分項が組み合わせ的に爆発します。

この規模では **Kane の方法**（部分速度に基づく d'Alembert 原理）が
最も効率的で、CarSim をはじめとする商用マルチボディソフトウェアの
内部で採用されています。

## 5. 自動車：非ホロノミック拘束の典型

### キネマティック自転車モデル（低速域）

低速で横滑りがない前提では、自動車を3つの状態方程式で記述できます:

$$\begin{align}
\dot{x} &= v\cos\psi \\
\dot{y} &= v\sin\psi \\
\dot{\psi} &= \frac{v}{L}\tan\delta \quad \text{← Ackermann 幾何}
\end{align}$$

$L$ はホイールベース、 $\delta$ は前輪操舵角です。
第3式は左右前輪が共通の旋回中心を持つ Ackermann 条件から直接導かれます。
この単純な形式が **Pure Pursuit・Stanley・LQR・MPC** 全ての基盤になります。

### 動力学自転車モデル（高速域）

高速域ではタイヤがスリップ角 $\alpha$ を取り、横力 $F_y = -C_\alpha\alpha$ を発生します。
Newton-Euler を線形化すると:

$$\begin{align}
m(\dot{v}_y + v_x\dot{\psi}) &= F_{yf}\cos\delta + F_{yr} & \text{(横方向の力の釣り合い)} \\
I_z\ddot{\psi} &= \ell_f F_{yf}\cos\delta - \ell_r F_{yr} & \text{(ヨーモーメントの釣り合い)}
\end{align}$$

状態 $\mathbf{x} = (v_y,\, \dot{\psi})^T$、入力 $u = \delta$ の **線形時不変系 $\dot{x} = Ax + Bu$** になります。
この形式が Rajamani 教科書 Ch.2 の標準形で、ESC・LKAS 設計の基礎です。

### シミュレーション結果

```
制御則          RMS偏差 [m]   最大操舵 [°]   特徴
Pure Pursuit       0.195         16.69   ルックアヘッド円弧追従
Stanley            0.204         25.39   横偏差を陽に使う高速復帰
LQR                0.191         35.00   Riccati 解析解 + FF補正
MPC                0.225         24.00   制約付き先読み最適化

ヨーレート整定時間: 0.1〜0.3秒（自動車の特徴的な速い応答）
スタビリティファクタ Kv = 0.00104（アンダーステア）
```

応答時間が 0.1〜0.3 秒という短さが自動車の特徴です。
ESC はこの「意図ヨーレート」と実ヨーレートの差を見て
0.1 秒以内に介入します。

## 6. 航空機：自由空間と固有モード

### 6自由度剛体運動（フル方程式）

航空機は地面拘束がない自由空間運動なので、
非ホロノミック拘束は存在しません。代わりに
機体座標系の完全な Newton-Euler 方程式が必要です:

$$\begin{align}
m(\dot{u} + qw - rv) &= F_x - mg\sin\theta & \text{(ピッチ軸周りのコリオリ項を含む)} \\
m(\dot{v} + ru - pw) &= F_y + mg\cos\theta\sin\phi \\
m(\dot{w} + pv - qu) &= F_z + mg\cos\theta\cos\phi
\end{align}$$

$$\begin{align}
I_x\dot{p} - (I_y - I_z)qr &= L & \text{(ロール: エルロン $\delta_a$ で制御)} \\
I_y\dot{q} - (I_z - I_x)rp &= M & \text{(ピッチ: エレベータ $\delta_e$ で制御)} \\
I_z\dot{r} - (I_x - I_y)pq &= N & \text{(ヨー: ラダー $\delta_r$ で制御)}
\end{align}$$

外力・モーメントは空気力で決まります:

$$F = \frac{1}{2}\rho V^2 S \cdot C_*(\alpha,\, \beta,\, q,\, \delta_a,\, \delta_e,\, \delta_r,\, \ldots)$$

### 縦運動・横運動の分離

対称な機体形状の線形化により、運動は2つに**自然分離**します。
これもラグランジュ形式では自明ではありませんが、
Newton-Euler の物理的な力の釣り合いから導くと見通しよく分かります。

```
縦運動 : (Δu, w, q, θ)  ← エレベータ δ_e で操作
横方向 : (β, p, r, φ)  ← エルロン δ_a + ラダー δ_r で操作
```

自動車では固有モードが問題化することはほぼありませんが、
航空機では設計の本質的な課題となります。
これも **媒質（空気）の低密度と自由空間運動** から来る特性です。

## 7. 船舶：高密度媒質と付加質量

### 自動車・航空機との決定的な違い

船舶が他の輸送機関と大きく異なる点は「媒質の高密度性」です。

| 現象 | 自動車 | 航空機 | 船舶 |
|---|---|---|---|
| 付加質量 | 無視できる | ほぼ無視できる | **船体と同オーダー** |
| 流体抗力 | 空気抵抗（小） | 空気抵抗（中） | **水の抵抗（大）** |
| 復原力 | タイヤ/路面 | 重力(静安定) | **浮力・メタセンタ** |
| 応答時間 | 0.1〜1秒 | 数秒〜分 | **数十秒〜数分** |

### Fossen の標準モデル

Thor I. Fossen (NTNU) による業界標準の定式化:

$$M\dot{\nu} + C(\nu)\nu + D(\nu)\nu + g(\eta) = \tau + \tau_{\text{wind}} + \tau_{\text{wave}}$$

ここで各変数は:

- $\eta$ : 慣性系の位置・姿勢 $(x,\, y,\, z,\, \phi,\, \theta,\, \psi)^T$
- $\nu$ : 船体座標系の速度・角速度 $(u,\, v,\, w,\, p,\, q,\, r)^T$
- $M = M_{RB} + M_A$ : 剛体慣性 + 付加質量
- $D(\nu)$ : 流体抗力（線形 + 二次項）
- $g(\eta)$ : 復原力・モーメント

この形式は Newton-Euler 形式の直接の拡張です。
付加質量 $M_A$ は「加速するとき周囲の水も一緒に加速する」効果で、
ラグランジュ形式でも表現できますが、物理的直感は Newton-Euler の方が掴みやすいです。

### Nomoto 1次モデル（制御向け簡略形）

針路制御には Nomoto の簡略モデルが広く使われます:

$$T\ddot{\psi} + \dot{\psi} = K\delta$$

ここで $T = 50\,\text{秒}$（本デモの中型コンテナ船）、 $K = 0.18$（舵効きゲイン）。

### シミュレーション結果

```
目標方位  : 30 度への変針
整定時間  : 124.8 秒（±1.5度以内）
最大舵角  : 35.0 度（舵角飽和）

初動で舵角飽和、その後減衰しながら整定。
自動車のヨー応答（<1秒）に対して、船は2分以上かかる。
→ 付加質量・流体減衰・大きな船体慣性の効果。
```

## 8. シミュレーション結果で見る違い

### 時間スケールの3桁の差

同じ「剛体の回転運動」を扱いながら、媒質と慣性の違いで
応答時間が3桁にわたって変化します:

```
自動車のヨー応答  : 0.1〜1秒       ← タイヤ摩擦・路面反力が即応
航空機 短周期     : 1〜10秒        ← 空気力の瞬時応答性
航空機 フゴイド   : 30〜1000秒     ← 速度↔高度の緩やかな交換
船舶の変針        : 数十秒〜数分   ← 高密度流体と大慣性
ロボットアーム    : 0.1〜数秒      ← ホロノミック拘束・電動アクチュエータ
```

### 定式化の違いが生む「素直さ」の違い

| 系 | 使うべき定式化 | 反対の定式化を使うと |
|---|---|---|
| ロボットアーム | ラグランジュ（$`M(q)\ddot{q} + C\dot{q} + g = \tau`$） | Newton-Euler では力の向きを座標変換で追跡する手間 |
| 自動車 | Newton-Euler（状態方程式直結） | ラグランジュでは未定乗数が必要 |
| 航空機 | Newton-Euler（モード解析） | ラグランジュでは回転項の整理に手間がかかる |
| 船舶 | Newton-Euler + Fossen 形式 | ラグランジュでは付加質量の扱いが複雑 |
| フルビークル(14DOF) | Kane の方法 | ラグランジュ・Newton-Euler とも式が爆発 |

- **グラフ⑤（フゴイド）**: 847秒の長周期で速度と高度がゆっくり振動。自動操縦なしでは14分かけて自然減衰
- **グラフ⑥（船舶変針）**: 2分かけて整定。初動の舵角飽和と付加質量の効果が見える

- **左（関節角度）**: 2つのリンクが複雑に回転する二重振り子的な自由運動

## 9. 定式化を選ぶための判断フロー

```
問題の運動方程式を立てる必要がある
│
├─ Q1: 多体系（6自由度以上の連結剛体）か？
│  │
│  └─ はい → [Kane の方法 / マルチボディ解析ソフト]
│             CarSim, Adams, Modelica 等
│
└─ 単体または少数剛体
   │
   ├─ Q2: 拘束はホロノミックか非ホロノミックか？
   │  │
   │  ├─ ホロノミック（座標関係で表せる、例: ロボット関節）
   │  │  │
   │  │  └─ Q3: 保存系（重力・弾性力が主）か？
   │  │     │
   │  │     ├─ はい → [ラグランジュ法] ★ エネルギー保存の美しさが活きる
   │  │     │          スカラ L = T - V から全て出る
   │  │     │
   │  │     └─ いいえ（非保存力が支配）
   │  │        → [ラグランジュ or Newton-Euler] どちらでも同程度
   │  │          制御設計が目的なら Newton-Euler が楽
   │  │
   │  └─ 非ホロノミック（速度拘束、例: タイヤの横滑りなし）
   │     │
   │     └─ [Newton-Euler] ★ 拘束を外力として素直に表現できる
   │        未定乗数（Lagrange-d'Alembert）は避けた方が楽
   │
   └─ Q4: 最終目的は制御設計か？
      │
      ├─ はい → [Newton-Euler] 状態方程式 ẋ = f(x,u) に直結
      │
      └─ いいえ（理論解析・エネルギー論）
         → 問題に応じて判断
```

### まとめ

| 使うべき定式化 | 問題の構造 | 典型例 |
|---|---|---|
| **ラグランジュ** | ホロノミック拘束 + 保存系 | ロボットアーム、惑星運動、弦の振動 |
| **Newton-Euler** | 非ホロノミック拘束 or 制御指向 | 自動車、航空機、船舶、宇宙機姿勢制御 |
| **Kane の方法** | 大規模多体系 | フルビークル、人体モデル、衛星展開機構 |

## 10. 参考文献

### 輸送機関（Newton-Euler）

- R. Rajamani, *Vehicle Dynamics and Control*, Springer, 2012.  
  自動車の2自由度線形モデルの標準テキスト。

- B. Etkin and L. D. Reid, *Dynamics of Flight: Stability and Control*, Wiley, 1996.  
  航空機の6自由度モデルと固有モード解析。

- T. I. Fossen, *Handbook of Marine Craft Hydrodynamics and Motion Control*, Wiley, 2011.  
  船舶の標準定式化。付加質量・Nomoto モデルの原典。

### ロボティクス（ラグランジュ）

- M. W. Spong, S. Hutchinson, M. Vidyasagar, *Robot Modeling and Control*, Wiley, 2005.  
  $M(q)\ddot{q} + C(q,\dot{q})\dot{q} + g(q) = \tau$ の標準導出。

- B. Siciliano et al., *Robotics: Modelling, Planning and Control*, Springer, 2009.  
  ラグランジュ法によるマニピュレータ動力学の包括的テキスト。

### 多体系（Kane の方法）

- T. R. Kane and D. A. Levinson, *Dynamics: Theory and Applications*, McGraw-Hill, 1985.  
  Kane 法の原典。部分速度に基づく d'Alembert 原理の定式化。

- H. Goldstein, C. Poole, J. Safko, *Classical Mechanics*, Addison-Wesley, 2002.  
  ホロノミック・非ホロノミック拘束の厳密な定義と Lagrange-d'Alembert 方程式。
