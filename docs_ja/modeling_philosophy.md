# 表現する対象に応じて、適したモデリング手法がある

> **このドキュメントがただ一つ伝えたいこと**
>
> **「正しい運動方程式」は一つではない。表現したい対象の構造が、適したモデリング手法を決める。**
>
> 同じ「剛体の運動」を扱っていても、対象が自動車なのか、ロボットアームなのか、
> 航空機なのか、船舶なのかによって、**素直に書ける定式化はまったく違う**。
> 本プロジェクトは、この一点を「動くコード」で示すために存在する。

---

## 1. 主張：手法は対象に従う

力学の教科書を分野ごとに開くと、奇妙なことに気づく。

- **ロボティクス**の教科書は、必ず **ラグランジュ方程式** で運動方程式を立てる。
- **自動車・航空機・船舶**の教科書は、ほぼ例外なく **Newton-Euler 形式** で書く。
- **フルビークル(サスペンション込み14自由度)** の商用ソフトは、内部で **Kane の方法** を使う。

これは流儀や好みの問題ではない。**対象の物理構造が、適した手法を選ばせている。**

| 表現したい対象 | 支配する構造 | 適したモデリング手法 |
|---|---|---|
| ロボットアーム | ホロノミック拘束 + 保存力(重力) | **ラグランジュ法** |
| 自動車 | 非ホロノミック拘束(タイヤ) + 非保存力(摩擦) | **Newton-Euler** |
| 航空機 | 自由空間 + 空気力(非保存) + 固有モード | **Newton-Euler** |
| 船舶 | 高密度媒質 + 付加質量 + 復原力 | **Newton-Euler(Fossen 形式)** |
| フルビークル(多体) | 大規模連結剛体 | **Kane の方法** |

**同じ「剛体力学」でありながら、対象が変われば適した道具が変わる。**
これが本プロジェクトの中心主張である。

---

## 2. なぜ「一つの正しい手法」ではないのか

重要なのは、**どの手法も物理的には等価に正しい**という点だ。
ラグランジュ法で自動車を、Newton-Euler でロボットアームを記述することも、
理論上は可能である。それでも人々が対象ごとに手法を変えるのは、
**「解けるか」ではなく「素直に書けるか」が違う**からだ。

手法の善し悪しは、次の3つの構造で決まる。

### ① 拘束の種類 ── ホロノミックか、非ホロノミックか

- **ホロノミック拘束**(座標どうしの関係、例:ロボットの関節)
  → 一般化座標を選ぶと拘束が消える。**ラグランジュ法が素直。**
- **非ホロノミック拘束**(速度の拘束、例:タイヤの横滑りなし)
  → 座標変換では消せず、ラグランジュでは未定乗数が要る。
  **Newton-Euler なら「タイヤが出す力」として外力に書くだけ。**

### ② 力の性質 ── 保存力か、非保存力か

- **保存力が主役**(重力・弾性力)
  → ポテンシャル $V$ に収まり、ラグランジアン $L = T - V$ が活きる。
- **非保存力が主役**(タイヤ摩擦・空気抵抗・流体抗力・推力)
  → $L$ の枠に入らず右辺の一般化力に押し込むだけ。
  ラグランジュの美点が消え、**Newton-Euler と労力が変わらない。**

### ③ 最終目的 ── 解析か、制御か

- **制御設計**が目的なら、状態方程式 $\dot{x} = f(x, u)$ が要る。
  → Newton-Euler は1階の状態方程式に直結。
  ラグランジュは $M(q)\ddot{q} + C\dot{q} + g = \tau$ の2階形で、
  $M^{-1}$ を取る一手間が入る。

この3つの問いに対象を通すと、適した手法が自ずと決まる。

## 3. 本リポジトリが示す4つの実例

本プロジェクトの各シミュレーションは、この主張の**実証**になっている。

### 自動車 ── 非ホロノミック拘束 → Newton-Euler

タイヤの「横滑りしない」拘束は速度の拘束(非ホロノミック)。
ラグランジュでは未定乗数が要るが、Newton-Euler なら横力を外力に書くだけ。
制御則(Pure Pursuit / Stanley / LQR / MPC)が全て状態方程式に直結する。
→ [`src/car_dynamic.cpp`](../src/car_dynamic.cpp), [`src/car_tracking.cpp`](../src/car_tracking.cpp)

### 航空機 ── 自由空間 + 固有モード → Newton-Euler

地面拘束がない自由空間運動。空気力(非保存力)が支配し、
短周期モード(約10秒)とフゴイドモード(約14分)という**固有モード**が
制御設計の主対象になる。力の釣り合いから見通しよく分離できる。
→ [`src/aircraft.cpp`](../src/aircraft.cpp)

### 船舶 ── 高密度媒質 + 付加質量 → Newton-Euler(Fossen 形式)

媒質の密度が高く、**付加質量**(加速時に周囲の水も動く効果)が
船体慣性と同オーダーで効く。応答は数十秒〜数分と遅い。
Fossen 標準形は Newton-Euler の直接拡張で、物理的直感が掴みやすい。
→ [`src/ship.cpp`](../src/ship.cpp)

### ロボットアーム(対比) ── ホロノミック拘束 + 保存力 → ラグランジュ

上の3つと対極。関節拘束はホロノミック、重力は保存力。
スカラ関数 $L = T - V$ の偏微分だけで運動方程式が機械的に出る。
駆動トルクなしで全エネルギーが保存されることも数値的に確認できる。
→ [`python/lagrangian_arm.py`](../python/lagrangian_arm.py)

**4つを並べて初めて、「対象が手法を選ぶ」ことが体感できる。**
これが同一リポジトリに輸送機関3種とロボットアームを同居させている理由である。

## 4. 対象から手法へ ── 判断の指針

新しい対象をモデリングするときは、対象の構造を次の順に問えばよい。

```
表現したい対象は何か？
│
├─ 多体系（6自由度以上の連結剛体）か？
│   └─ はい → Kane の方法 / マルチボディ解析ソフト
│
├─ 拘束は非ホロノミック（速度拘束）か？
│   └─ はい → Newton-Euler（拘束を外力として書ける）
│
├─ 非保存力（摩擦・抗力・推力）が支配的か？
│   └─ はい → Newton-Euler（ラグランジュの利点が活きない）
│
├─ 制御設計が最終目的か？
│   └─ はい → Newton-Euler（状態方程式に直結）
│
└─ ホロノミック拘束 + 保存力が主で、解析が目的
    └─ はい → ラグランジュ法（スカラ L = T - V が活きる）
```

**手法を先に決めて対象を押し込むのではない。対象を観察し、その構造に手法を従わせる。**
